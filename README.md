# Alessandro Chessari — academic website

Source for [aleeschessari.github.io](https://aleeschessari.github.io), built with [al-folio](https://github.com/alshedivat/al-folio).

## Main content

- `_pages/about.md` — biography and homepage
- `_pages/projects.md` — research overview
- `_pages/teaching.md` — teaching experience
- `_bibliography/papers.bib` — publications
- `_data/cv.yml` — web CV
- `assets/pdf/alessandro_chessari_cv.pdf` — downloadable CV
